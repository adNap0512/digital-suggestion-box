# Cursor Hooks（サンプル）

## 概要

Hooks は Cursor のライフサイクルイベント（ファイル編集後など）で自動的にコマンドを実行する仕組みです。

## 今回の方針

- `hooks.json.sample` に **説明用サンプル** のみ配置
- **実際の `hooks.json` は置いていない**（有効化しない）

## サンプルの内容

ファイル編集後（`afterFileEdit`）に `npm test` を実行する設定例です。

## 有効化しない理由

1. **セキュリティ**: Hooks は自動でシェルコマンドを実行するため、意図しない操作のリスクがある
2. **実行負荷**: 編集のたびにテストが走り、開発体験が重くなる

## 発表での説明例

> Hooks はファイル編集後に自動でテストを走らせる用途を想定しました。ただし、自動でコマンドが実行される仕組みのため、安全性と実行負荷を考慮し、今回はサンプル設定として整理しました。

## 有効化する場合

1. `hooks.json.sample` を `hooks.json` にリネーム
2. プロジェクトルートで `npm install` 済みであることを確認
3. チーム内で合意のうえ運用する
