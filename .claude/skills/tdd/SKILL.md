# TDD Skill

## 目的

TDD を意識して、小さな単位で実装を進める。

## 作業手順

1. 今から実装する小さな単位を決める
2. 先にテスト観点を書く
3. テストコードを作成する
4. 最小限の実装をする
5. テストを実行する
6. 必要ならリファクタリングする

## 制約

- 一度に大きく作りすぎない
- 主要な表示項目、フォーム入力、フィルタ、共感ボタンを必ずテスト対象にする
- カバレッジ 80% 以上を目指す
- テストが通っていない状態で完了しない
- `.cursor/rules/test-rule.mdc` を守る

## 起動について

利用者が明示的に `/tdd` で開始する想定。
副作用のある実装フローのため、AI による自動起動は無効（`disable-model-invocation: true`）。
