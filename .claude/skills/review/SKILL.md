# Review Skill

## 目的

実装内容をレビューし、問題があれば優先度順に修正案を出す。

## 確認観点

1. DESIGN.md に沿っているか
2. 3 画面が揃っているか
3. ダミーデータで利用イメージが伝わるか
4. テストが書かれているか
5. カバレッジ 80% 以上を満たせる構成か
6. コンポーネントが肥大化していないか
7. フィルタ処理や共感処理がテストしやすいか
8. README に起動方法、テスト実行方法、画面概要があるか

## 出力形式

- 問題があれば優先度順（高 / 中 / 低）に修正案を出す
- 問題がなければ、満たしている観点を簡潔にまとめる

## 起動について

実装レビューが必要なときに AI が自動利用してもよい。
利用者が `/review` で手動起動することもできる。
